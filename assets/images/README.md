# Portfolio Images

This folder contains all the images used in the portfolio website. Please add the following images:

## Required Images:

1. **profile.jpg** - Your professional headshot/profile picture (300x300px recommended)
2. **about.jpg** - A photo of you working or in your workspace (400x400px recommended)
3. **project1.jpg** - Screenshot or mockup of your first project (400x250px recommended)
4. **project2.jpg** - Screenshot or mockup of your second project (400x250px recommended)
5. **project3.jpg** - Screenshot or mockup of your third project (400x250px recommended)

## Image Guidelines:

- Use high-quality images with good lighting
- Ensure images are properly sized for web (optimized file sizes)
- Use consistent styling across all images
- Consider using placeholder images from services like Unsplash or Pexels if you don't have your own images yet
